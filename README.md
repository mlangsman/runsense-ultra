# runsense-ultra

A running coach that lives inside Claude. Connect the watch you already wear, and Claude shows your runs with maps, splits and laps, keeps your training log, tracks how each run felt, warns you when volume climbs too fast, and coaches you towards the goal you set.

Status: foundations. The database schema with row-level security and the landing page are in place; accounts and per-user sync are next. Two tools render in Claude, a history list and a workout detail with map, splits and laps, from one intervals.icu account, and an email when a workout syncs, with an "Open in Claude" link.
